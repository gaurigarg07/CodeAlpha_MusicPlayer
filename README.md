🎧 SWAY — Music Player

Find your rhythm. Embrace your mood. Let the music flow.

SWAY is a modern, mood-inspired music player designed to make listening to music feel personal, seamless, and immersive. Explore music, discover your vibe, and enjoy a smooth listening experience with a clean and interactive interface.

✨ Features

- 🎵 Music playback with player controls
- 🔍 Search songs
- ❤️ Add songs to favourites
- 📂 Browse your music library
- 📝 Manage playlists
- ⏭️ Next and previous song controls
- 🎨 Modern and responsive user interface
- 🖼️ Album artwork and song images

🛠️ Built With

- HTML5
- CSS3
- JavaScript

🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
4. Enjoy listening to music with SWAY!
